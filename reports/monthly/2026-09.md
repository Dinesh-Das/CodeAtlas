# CodeAtlas dogfood — September 2026

Scope: P0-P7 implementation audit against CodeAtlas itself and the checked-in release evidence.

The release manifest contains 12 unique public repositories pinned to full commits across Linux,
macOS, and Windows, plus a pinned large-repository benchmark. Those repository validations were
recorded with `0.10.0-beta.3`; they demonstrate the release line but are not presented as fresh
proof of the final `0.10.0` package artifact. The stable release gate remains the authority for
version, package checksum, evidence age, relationship thresholds, and benchmark budgets.

Implemented this month:

- canonical bounded SQLite queries and compact MCP tools;
- guided system tours, contract intelligence, change preparation, and source-free PR review;
- tracked repository knowledge with ownership and freshness checks;
- registry-ready package metadata and six host setup targets;
- an opt-in source-free local report and independent adapter precision/recall gate.

The Windows disposable-consumer package smoke reached the first generated architecture overview
25.4 seconds after starting tarball installation, below the three-minute gate. This is a local
release check, not a cross-machine percentile; release CI repeats the package path on all three
operating systems.

Before a stable announcement, rerun repository validation with the final npm tarball, refresh the
large-repository benchmark, record live smoke tests for configuration-validated hosts, and publish
the maintainer-authenticated registry entry. The two-minute demo protocol is ready in
`docs/demo/difficult-change.md`; no comparative outcome is claimed until its paired manifest is
recorded.
